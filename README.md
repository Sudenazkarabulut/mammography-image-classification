\# Mammography Image Classification



\## Overview



This project focuses on breast abnormality classification from mammography images using deep learning techniques.



The system applies image enhancement, transfer learning, and attention mechanisms to improve diagnostic performance.



\## Features



\- CLAHE preprocessing

\- Data augmentation

\- DenseNet121 backbone

\- Attention mechanism

\- Focal Loss

\- Transfer Learning

\- ROC-AUC evaluation

\- Confusion Matrix analysis



\## Dataset



VinDr-Mammo Dataset



\## Technologies



\- Python

\- TensorFlow

\- Keras

\- OpenCV

\- Scikit-Learn



\## Results



Performance was evaluated using:



\- Accuracy

\- Precision

\- Recall

\- F1-score

\- ROC-AUC
